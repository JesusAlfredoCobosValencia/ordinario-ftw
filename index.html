Bienvenido

Este sitio muestra informacion de una liga de futbol. En las diferentes paginas se podran ver equipos, jugadores, partidos, tabla de posiciones y noticias.

Los datos seran escritos manualmente y algunas secciones se mostraran de manera dinamica con JavaScript y XML.
